# Atlas Launcher

**Atlas Launcher** — личный C++/Qt лаунчер Minecraft Java Edition для Windows 7 SP1 и новее. Проект использует Qt 5.15 Widgets, C++17 и CMake. Интерфейс выполнен в стиле **Obsidian Atlas**: тёмная графитовая рабочая область, бирюзовый акцент, карточки и понятная навигация.

На текущем этапе реализованы базовое окно приложения, библиотека локальных экземпляров, сохранение профилей в JSON, создание Vanilla/Fabric/Forge/NeoForge/Quilt-профилей, офлайн-центр и расширенная форма настроек. Сетевой каталог, загрузчик, импорт пакетов и запуск Java подключаются следующими модулями.

## Правовые границы

Лаунчер не обходится авторизацию Minecraft и не содержит пиратских игровых файлов. Офлайн-режим предназначен для локального управления уже имеющимися легальными файлами, импортированных пользовательских пакетов и локальной работы без сети. Официальная авторизация Microsoft и загрузка игровых файлов должны быть добавлены с соблюдением условий Mojang/Microsoft.

## Требования

Для разработки на Windows рекомендуется Qt 5.15.x с компилятором MSVC или MinGW, CMake 3.16+, Git и Inno Setup 6. Целевой бинарник собирается как 64-битное приложение; отдельная 32-битная конфигурация возможна, если выбранный Qt-комплект также 32-битный. Qt 6 для целевой совместимости с Windows 7 не используется.

## Сборка в Qt Creator

Откройте `CMakeLists.txt` в Qt Creator, выберите комплект с Qt 5.15, настройте каталог сборки и нажмите **Build**. Для запуска нужен только собранный `AtlasLauncher.exe` и каталог Qt runtime рядом с ним. На рабочем компьютере с Windows 7 необходимо проверить TLS-библиотеки Qt и доступные корневые сертификаты.

## Сборка из командной строки

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Если используется MinGW-комплект Qt 5.15, замените генератор на соответствующий `MinGW Makefiles` и передайте путь к `CMAKE_PREFIX_PATH`.

## Пользовательские данные

Приложение хранит настройки и экземпляры в каталоге Qt `AppDataLocation`, на Windows обычно внутри `%APPDATA%/Atlas/Atlas Launcher`. Внутри находятся `settings.json`, `atlas.log` и папка `instances`.
