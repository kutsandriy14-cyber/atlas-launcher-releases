# Atlas Launcher — контракт переделки

## Честный аудит версии 0.1.0

Пользовательская проверка показала, что текущая сборка имеет только каркас интерфейса. Это подтверждается кодом: создание экземпляра сохраняет один `instance.json`; выбор версии — свободное текстовое поле; поиск Modrinth и CurseForge получает только карточки; очередь загрузок не существует; Java не устанавливается; запуск открывает информационное окно вместо процесса Java. Такая версия не должна позиционироваться как рабочий лаунчер.

| Область | Состояние в 0.1.0 | Что будет считаться готовым после переделки |
|---|---|---|
| Версии Minecraft | Поле ручного ввода | Список версий из официального version manifest, выбор release/snapshot и фактическая установка всех объявленных файлов. |
| Vanilla | Не реализована | Загрузка client JAR, version JSON, libraries и asset index с проверкой SHA-1 и отображением прогресса. |
| Java | Только текстовое поле | Поиск существующей Java, выбор подходящей версии и установка runtime в `data/runtime/<major>` через очередь загрузок. |
| Загрузки | Текст «очередь пуста» | Постоянная очередь задач, пауза/повтор, скорость, прогресс, атомарные временные файлы, SHA-проверка и читаемая ошибка. |
| Экземпляры | Только папки и JSON | Статусы «не установлен / устанавливается / готов / ошибка», удаление, переустановка, независимые game directory и профили параметров. |
| Запуск | Диалог-заглушка | Построение Java-аргументов из version JSON, лог процесса, остановка процесса и статус завершения. Запуск требует законного официального профиля. |
| Microsoft-вход | Отсутствует | Отдельный модуль device-code OAuth с настраиваемым client ID владельца; нельзя вшивать общий/чужой секрет или обходить лицензию. |
| Fabric/Forge/NeoForge/Quilt | Список в окне создания | Установщик добавляется только после получения официальных метаданных и реализации реальной установки; до этого элементы не будут показаны как рабочие. |
| Modrinth/CurseForge | Только поиск | Установка выбранного файла, зависимостей и контрольной суммы; для CurseForge нужен личный разрешённый API-ключ. |
| Настройки | Плоская форма | Разделы с валидацией, кнопками «Обзор», «Проверить Java», «Установить Java», профилями по экземпляру и сохранением только реально используемых параметров. |
| Интерфейс | Часть layouts выходит за окно | Адаптивные компоновщики, scroll area у каждой длинной страницы, минимум жёстких ширин, корректный high-DPI и тест при 1024×768. |

## Работающий первый релиз

Ближайшая рабочая поставка обязана позволять выбрать реальную Vanilla-версию, скачать нужную Java в собственную папку лаунчера, установить Vanilla-файлы с проверкой хешей и показать весь ход операции в очереди. На экран не попадёт кнопка, которая не вызывает реальное действие или не сообщает о явном ограничении.

Запуск игры будет добавлен для официального профиля Microsoft. Я не буду реализовывать обход лицензии, генерацию поддельных сессий или распространение игровых файлов без законного доступа. Офлайн-возможности сохранятся для управления уже установленными локальными экземплярами и их локальным контентом.

## Критерии приёмки

1. Новая установка не требует ручного ввода строки версии: список загружается и фильтруется.
2. При выборе Vanilla пользователь видит точный план скачивания и может отменить его.
3. `runtime` устанавливается внутри папки данных Atlas Launcher, а не в системную Java.
4. Каждая загрузка пишет временный файл, сверяет SHA-1 перед заменой и не оставляет повреждённый целевой файл.
5. На экране «Загрузки» показываются название, размер, прогресс, скорость, состояние и текст ошибки.
6. При размере окна 1024×768 страница прокручивается, но ни один контрол не рисуется вне окна.
7. Кнопка «Запуск» остаётся выключенной, пока экземпляр или официальный профиль не готовы, и объясняет причину.
