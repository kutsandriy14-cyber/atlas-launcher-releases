# Аудит настроек и Java перед переделкой интерфейса

## Ориентир интерфейса

Пользователь предоставил скриншоты лаунчера как ориентир по **сценарию**, а не как объект для копирования. В Atlas должен быть понятный менеджер сборок с отдельным редактором профиля: базовые параметры видны сразу, а сложные параметры открываются в блоке «Больше настроек». Настройки лаунчера должны быть распределены по читаемым разделам, а каждый переключатель обязан либо сохраняться, либо немедленно менять реальное поведение.

## Уже реализовано и требует переиспользования

| Возможность | Текущее состояние | Реальный эффект |
|---|---|---|
| Локальная Java Atlas | Реализована через Adoptium API, HTTPS, SHA-256 и 7-Zip | Скачивает Windows x64 JRE в `runtime/<major>` рядом с данными Atlas; системная Java не требуется |
| Java 8 / 11 / 17 / 21 | Сервис умеет запросить любую поддерживаемую major-версию | Готовая среда определяется по `bin\\javaw.exe` и сохраняется с metadata |
| Автозагрузка при запуске | Частично реализована | Если профиль использует managed Java и подходящая среда отсутствует, запуск ждёт её установки |
| Выбор своего javaw.exe | Частично реализован в редакторе сборки | Путь сохраняется, но выбирается без проверки фактической версии Java |
| Определение требуемой Java | Реализовано в MainWindow | Для Minecraft применяется major-версия, вычисленная из metadata и нормализованная к 8, 11, 17 или 21 |
| Профильные JVM-аргументы | Реализованы | Передаются в реальную командную строку запуска, кроме режима safe mode |

## Выявленные проблемы

Текущий интерфейс одновременно показывает глобальную «внешнюю Java» и локальную Java Atlas, но не объясняет их приоритет. Нажатие «Использовать локальную» записывает путь локальной Java в глобальное поле, хотя профиль по умолчанию и так использует managed Java. Это создаёт впечатление, что Java выбрана, но не даёт прозрачного режима выбора.

В профиле сейчас доступны только два режима: «Локальная Java Atlas» и «Свой javaw.exe». Нет отдельного режима **«Автовыбор Java»**, нет карточки с вычисленной требуемой версией для выбранной Minecraft-версии и нет проверки выбранного исполняемого файла через `java -version` до сохранения. Глобальные настройки также содержат ряд уже описанных в модели параметров, которые не выведены в интерфейс и не сохраняются из формы.

## Решение

Вводятся три понятных режима Java для профиля.

| Режим | Смысл | Поведение |
|---|---|---|
| **Автовыбор (рекомендуется)** | Atlas определяет подходящую Java для Minecraft и загрузчика | Использует уже установленную локальную Java требуемой major-версии; при отсутствии скачивает её в Atlas и продолжает установку/запуск |
| **Локальная Java Atlas** | Пользователь фиксирует использование Java из папки Atlas | Показывает доступные локальные Java, кнопку скачивания выбранной версии и точный путь `javaw.exe` |
| **Свой javaw.exe** | Пользователь выбирает внешний исполняемый файл | Atlas проверяет существование, запускает `javaw.exe -version`, показывает определённую major-версию и блокирует сохранение при несовместимости |

Кнопка **«Скачать подходящую Java»** будет доступна в мастере сборки и определит major-версию по выбранной Minecraft-версии. В общих настройках будет отдельный раздел Java с перечнем Java 8, 11, 17 и 21, статусом каждой локальной среды, кнопкой скачивания, выбором файла и тестом выбранной Java. Для старых Windows будет использоваться JRE из той же проверяемой официальной поставки, что и текущий JavaRuntimeService.

## Рамки реализации

Поддерживается только x64 Windows, поскольку portable Atlas — x64. Механизмы обхода лицензии Minecraft и замены Microsoft-авторизации не добавляются. Java устанавливается исключительно в локальную папку данных Atlas, если пользователь явно не выбрал собственный `javaw.exe`.
