# Atlas Launcher — состояние MVP

**Atlas Launcher** — исходный C++/Qt-проект персонального лаунчера Minecraft Java для Windows 7 SP1 x64 и новее. В этой поставке реализована безопасная основа: интерфейс Obsidian Atlas, локальные экземпляры, импорт файловых пакетов и каталог контента. Проект не содержит Minecraft, не подменяет проверку владения игрой и не реализует обход авторизации.

| Подсистема | Состояние | Что сделано |
|---|---:|---|
| Интерфейс | Готово для MVP | Тёмная тема Obsidian Atlas, навигация, домашняя страница, библиотека, каталог, очередь и прокручиваемые страницы. Минимальный размер снижен до 800×520, длинные элементы переносятся; визуальный аудит на реальном Windows 7 остаётся перед релизом. |
| Экземпляры | Готово для MVP | Локальное создание, JSON-метаданные, отдельные папки экземпляров и выбор Vanilla, Fabric, Quilt, Forge или NeoForge. Запуск разрешён только после подтверждённой установки выбранного профиля. |
| Настройки | Частично | Реально применяются внешняя/локальная Java, min/max RAM, Microsoft client ID и папка экземпляров; проверка хешей обязательна. Параллельность загрузок, лимит трафика, анимации и профильные переопределения пока не заявляются готовыми. |
| Локальная Java | Готово | JRE 8/11/17/21/25 загружается из Eclipse Adoptium в папку Atlas, проверяется SHA-256 и распаковывается bundled 7-Zip без изменения системной Java. |
| Vanilla Minecraft | Готово | Получение Mojang manifest, client JAR, libraries, Windows natives и assets с SHA-1-проверкой и повторным использованием проверенных файлов. |
| Офлайн-режим | Готово для локальных экземпляров | Профиль с детерминированным offline UUID запускает установленный профиль через локальную Java. Это не заменяет лицензию для сетевой игры. |
| Microsoft-аккаунт | Готово при настройке владельца | Device-code flow, обмен Microsoft → Xbox Live → XSTS → Minecraft Services и DPAPI-защита refresh token в Windows. Владелец должен указать собственный Microsoft Application (client) ID. |
| Запуск игры | Готово для установленного профиля | Для Vanilla, Fabric, Quilt, Forge и NeoForge после подтверждённой установки строятся Windows classpath и natives, объединяются наследуемые metadata, подставляются version arguments, запускается и останавливается `javaw.exe`, лог процесса сохраняется в журнал Atlas. |
| Формат сборок | Готово | `package.json` schemaVersion 1, локальные файлы, `overrides`, описания удалённых файлов, отклонение абсолютных и обходных путей. |
| Modrinth | Готово для ограниченной установки | Асинхронный поиск через публичный API v2, фильтры по версии, загрузчику и типу; выбранный первичный файл с опубликованным SHA-512/SHA-1 ставится в `mods`, `resourcepacks` или `shaderpacks` выбранного экземпляра. Зависимости, модпаки и миры пока не устанавливаются автоматически. [1] |
| CurseForge | Готово для ограниченной установки при наличии ключа | Поиск и получение выбранного файла через официальный API с переданным пользователем ключом в заголовке `x-api-key`; HTTPS-файл с опубликованным SHA-1 ставится в `mods`, `resourcepacks` или `shaderpacks` выбранного экземпляра. Ключ остаётся только в оперативной памяти; зависимости, модпаки и миры пока не устанавливаются автоматически. [2] [3] |
| Установщик | Готово | Inno Setup-скрипт, развёртывание Qt через `windeployqt`, инструкция по сборке. |
| Автотесты | Готово | CTest проверяет импорт пакета и блокировку `..`, Unix-абсолютных, Windows drive-letter и UNC-путей. |

## Формат файловой сборки

Сборка — это обычная папка с `package.json` в корне. В секции `files` указываются локальные или удалённые файлы. Локальные копируются при импорте, а записи `modrinth` и `curseforge` остаются в очереди для будущего менеджера загрузок. Значение `source` не интерпретируется как команда, ссылка на исполняемый файл или сценарий.

```json
{
  "format": "atlas-launcher-package",
  "schemaVersion": 1,
  "name": "Моя Fabric-сборка",
  "version": "1.0.0",
  "minecraft": "1.20.1",
  "loader": { "kind": "fabric", "version": "0.15.11" },
  "files": [
    { "path": "mods/example.jar", "source": "local" }
  ],
  "overrides": ["config", "resourcepacks", "saves"]
}
```

## Следующая разработка

| Приоритет | Модуль | Требуемый результат |
|---:|---|---|
| 1 | Матрица совместимости | Проверить в Windows установку и запуск каждой поддерживаемой связки Minecraft/Java/Vanilla/Fabric/Quilt/Forge/NeoForge. |
| 2 | Загрузки каталога | Добавить разрешение зависимостей, модпаки, миры, выбор файлов, возобновление и подробный журнал ошибок. |
| 3 | Импорт экосистем | Импорт Modrinth `.mrpack`, CurseForge manifest-пакетов и Atlas package folders с явной обработкой файлов, которые нельзя автоматически скачать. |
| 4 | Профили и резервные копии | Переопределения памяти/Java для экземпляра, экспорт, снимки конфигурации и восстановление. |
| 5 | Настройки | Добавить только реально применяемые параметры сети, очереди и оформления с явной проверкой эффекта. |

> Ключ CurseForge нельзя вшивать в код, общий публичный конфиг или распространяемый установщик. Официальные условия требуют индивидуального ключа и запрещают его разглашение. [3]
