Atlas Launcher 0.2.2 — portable-сборка для Windows 7 SP1 x64 и новее

Установка и запуск

1. Распакуйте ZIP-архив целиком в отдельную папку с коротким путём латиницей. Не запускайте EXE прямо из ZIP.
2. Запускайте AtlasLauncher.exe, не перемещая DLL, папки platforms, tools и licenses.
3. Перед первым использованием сети можно запустить AtlasTLSProbe.exe. При исправной поставке в консоли должны быть строки supportsSsl=true и httpStatus=200. Это подтверждает, что Qt загрузил OpenSSL и получил официальный Mojang manifest по HTTPS.
4. Личные настройки, профили, локальная Java и игровые экземпляры создаются в профиле пользователя. Системная Java, системный PATH и реестр Windows не меняются.
5. На странице «Библиотека» нажмите «Новая сборка», выберите версию Minecraft и Vanilla / Fabric / Quilt / Forge / NeoForge, затем сохраните. Atlas сразу начнёт скачивать основу Minecraft и требуемую локальную Java. После завершения нажмите «Играть». Расширенные настройки профиля (папка, разрешение, память, Java и аргументы) находятся в раскрываемом блоке «Больше настроек».
6. Для лицензированного аккаунта укажите собственный Microsoft Application (client) ID в настройках. Пароль Microsoft в Atlas не вводится: используется device-code вход в браузере. Офлайн-профиль предназначен только для локальной игры.
7. Для CurseForge требуется ваш собственный API-ключ; он действует только в памяти текущего сеанса и не записывается в файл.

Состав набора

В portable-сборку включены Qt 5.15.2, MinGW runtime, OpenSSL 1.1.1w x64 и 7-Zip Extra. DLL OpenSSL обязательны для HTTPS в Qt 5.15; их отсутствие вызывало ошибку TLS initialization failed в предыдущем архиве. Папка tools обязательна: 7-Zip распаковывает только проверенные архивы локальной Java внутри папки данных Atlas.

Ограничения

Сборка не содержит Minecraft и не обходят лицензию или Microsoft-авторизацию. Установка контента Modrinth и CurseForge ограничена одиночными проверяемыми файлами модов, ресурспаков и шейдеров. Модпаки, миры, автоматические зависимости и возобновление загрузок пока не реализованы. Перед постоянным использованием выполните проверку на чистой Windows 7 SP1 x64 с актуальными корневыми сертификатами.
