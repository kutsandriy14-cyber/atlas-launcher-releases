# Архитектура Atlas Launcher

**Atlas Launcher** — нативный лаунчер Minecraft Java Edition для Windows 7 SP1 и новее. Проект создаётся как локальное приложение: оно хранит экземпляры игры в выбранной пользователем папке, не требует постоянного фонового сервиса и не передаёт данные на собственный сервер.

> Цель первого релиза — дать пользователю красивое, автономное управление легально полученными экземплярами Minecraft, загрузчиками модов и открыто распространяемым контентом.

## 1. Технологический выбор

| Область | Выбор | Причина |
|---|---|---|
| Язык | C++17 | Устойчивый современный стандарт с поддержкой в цепочках сборки для Windows 7. |
| Интерфейс | Qt Widgets 5.15 LTS | Нативные контролы, стабильная работа на старых системах и полный контроль визуального стиля без требований к современной видеокарте. |
| Сборка | CMake 3.21+ | Открытая, воспроизводимая конфигурация для Qt Creator, Visual Studio и CI. |
| Сеть | `QNetworkAccessManager` | Асинхронные HTTP-запросы, TLS и загрузки без блокировки интерфейса. |
| Данные | JSON через Qt Core | Читаемые пользователем профили, настройки и манифесты. |
| Установка | Inno Setup | Установка приложения, ярлыки, деинсталлятор и выбор каталога. |

Qt Widgets выбран вместо Qt Quick, поскольку для поддержки Windows 7 важнее предсказуемая отрисовка без зависимости от драйверов OpenGL. Визуально интерфейс останется современным за счёт собственной палитры, скруглённых карточек, теней, анимированных прогресс-баров и SVG-иконок.

## 2. Концепция интерфейса

Интерфейс называется **Obsidian Atlas**. Это тёмная графитовая рабочая область с акцентом бирюзового цвета. В верхней части показаны выбранный экземпляр, версия игры и крупная кнопка запуска. Слева расположена постоянная панель навигации, а рабочая область использует карточки и таблицы с ясной типографикой.

| Экран | Назначение |
|---|---|
| Главная | Выбор экземпляра, быстрый запуск, статус Java, память и последние события. |
| Библиотека | Создание, клонирование, архивирование и запуск экземпляров. |
| Создать экземпляр | Vanilla, Forge, NeoForge, Fabric, Quilt или импорт пакета. |
| Каталог | Поиск и установка разрешённого контента из Modrinth; отдельная вкладка CurseForge активируется после добавления персонального ключа. |
| Импорт/экспорт | Работа с архивом сборки и файловым пакетом с `package.json`. |
| Загрузки | Очередь, скорость, размер, хэш, повтор при ошибке и отмена. |
| Настройки | Java, память, графика, папки, сеть, приватность, обновления и диагностика. |

## 3. Границы лицензирования и офлайн-работы

Приложение не содержит обхода лицензии, подмены токенов, генерации «премиум»-аккаунтов, скачивания защищённых игровых файлов без права на них или скрытия источника загружаемого контента. Такие функции не будут реализовываться.

Офлайн-функциональность в проекте означает: работа с уже существующими локальными экземплярами, импорт ранее скачанных легальных файлов, локальная настройка профилей и запуск экземпляра с сохранённой действующей официальной сессией, когда игра и её ресурсы уже находятся на диске. Для сетевых серверов по-прежнему применяются правила их владельцев.

Официальная авторизация Microsoft добавляется отдельным модулем по OAuth 2.0 Device Code Flow; токены хранятся только локально через Windows Credential Manager. До её добавления приложение будет корректно управлять контентом и экземплярами, но не заявлять о праве на скачивание игровых файлов.

## 4. Модули проекта

```text
src/
  app/                 Точка входа, стили, композиция приложения
  ui/                  Окна, страницы, карточки, диалоги и модели Qt
  domain/              Instance, Loader, PackageManifest, DownloadTask
  services/            Instances, import/export, Java, downloads, запуск
  providers/           Modrinth, CurseForge, официальный манифест версий
  infrastructure/      HTTP, JSON, файловая система, хэширование, журнал
assets/                SVG, QSS-тема, изображения
installer/             Inno Setup
examples/              Демонстрационные package.json и instance.json
```

Код UI зависит только от сервисов и моделей представления. Сетевые провайдеры не знают о виджетах. Это позволяет добавлять новые источники контента, не переписывая интерфейс.

## 5. Источники контента

| Подход | Компромиссы | Стоимость | Сложность настройки |
|---|---|---:|---:|
| Прямая интеграция Modrinth в приложении | Открытый каталог, поиск и загрузка поддерживаемых файлов; необходим корректный User-Agent и соблюдение лимитов. | Бесплатно | Низкая |
| Интеграция CurseForge по персональному ключу | Даёт доступ к официальному API, но ключ нельзя вшивать в опубликованный бинарник; применяются условия CurseForge. | Зависит от условий CurseForge | Средняя |
| Локальный импорт файлового пакета | Работает без ключей и сети; пользователь сам отвечает за происхождение файлов. | Бесплатно | Низкая |

Первый рабочий релиз использует Modrinth и локальный импорт. Поддержка CurseForge спроектирована как отключаемый провайдер: пользователь помещает свой ключ в настройки или переменную окружения, а ключ не сохраняется в экспортируемых пакетах. Это следует из официальных условий, согласно которым ключ уникален, не подлежит передаче и не должен раскрываться третьим лицам.[2]

Modrinth допускает большинство запросов без токена, требует уникальный `User-Agent` и публикует текущий лимит в 300 запросов в минуту на IP.[1] Реализация поэтому добавляет ограничитель, кэш только локальных отображаемых метаданных с ручной очисткой, обработку `429`/`410` и проверку SHA-1/SHA-512 перед установкой.

## 6. Модель экземпляра

Каждый экземпляр хранится в самостоятельной папке и имеет файл `instance.json`.

```json
{
  "schemaVersion": 1,
  "id": "skyfactory-local",
  "name": "Sky Factory Local",
  "minecraft": "1.20.1",
  "loader": { "kind": "forge", "version": "47.2.0" },
  "java": { "path": "", "minMemoryMiB": 1024, "maxMemoryMiB": 4096 },
  "paths": { "game": ".", "mods": "mods", "resourcePacks": "resourcepacks", "saves": "saves" },
  "createdAt": "2026-08-11T00:00:00Z"
}
```

Менеджер экземпляров проверяет пути на выход за пределы корня, автоматически создаёт стандартные папки `mods`, `resourcepacks`, `saves`, `shaderpacks`, `config` и `screenshots`, а удаление сначала переносит экземпляр в локальную корзину лаунчера.

## 7. Формат файловой сборки

Файловая сборка — это ZIP-архив с `package.json` в корне. Она может содержать свободно распространяемые override-файлы и список декларативных зависимостей. Лаунчер никогда не принимает из манифеста произвольные команды для запуска.

```json
{
  "format": "atlas-launcher-package",
  "schemaVersion": 1,
  "name": "Example Adventure Pack",
  "version": "1.0.0",
  "minecraft": "1.20.1",
  "loader": { "kind": "fabric", "version": "0.15.11" },
  "files": [
    {
      "path": "mods/example.jar",
      "source": "modrinth",
      "projectId": "P7dR8mSH",
      "versionId": "example-version-id",
      "sha512": "optional-expected-hash"
    }
  ],
  "overrides": ["config", "options.txt", "resourcepacks"]
}
```

При импорте валидатор проверяет схему, не допускает абсолютные пути или `..`, показывает пользователю план установки, а затем загружает только явно поддерживаемые источники либо копирует файлы из архива. Для импортов CurseForge добавляется отдельный адаптер после получения пользовательского API-ключа и подтверждения условий.

## 8. Настройки

Настройки разделены на профили: глобальные, аккаунт, экземпляр и временные параметры запуска. Приоритет: временные → экземпляр → аккаунт → глобальные. В интерфейсе будет кнопка сброса каждого уровня и предпросмотр итоговой конфигурации.

| Группа | Основные параметры |
|---|---|
| Java | Автопоиск, путь к `javaw.exe`, аргументы JVM, 32/64-битная проверка, профиль памяти. |
| Игра | Размер окна, полноэкранный режим, каталог экземпляров, папка скриншотов, аргументы игры. |
| Контент | Версии Minecraft, загрузчики, типы проектов, каналы release/beta/alpha, папка загрузок. |
| Сеть | Ограничение скорости, число параллельных загрузок, прокси, тайм-аут, повтор ошибок. |
| Приватность | Режим журналов, очистка кэша, локальное хранение сеансов, отключение телеметрии. |
| Интерфейс | Тема, масштабирование, компактные карточки, язык, анимации, уведомления. |
| Безопасность | Проверка хэшей, подтверждение внешних файлов, резервное копирование перед импортом. |

## 9. Установка и распространение

Inno Setup собирает отдельный установщик `AtlasLauncher-Setup.exe`, который устанавливает приложение в `Program Files`, сохраняет пользовательские данные в `%APPDATA%/AtlasLauncher`, предлагает ярлыки и запускает проверку Java только после первого старта. Файлы игры и пользовательские сборки не включаются в установщик.
