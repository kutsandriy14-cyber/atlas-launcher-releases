# Atlas Launcher: упрощённый сценарий сборки

## Цель переделки

Пользователь должен суметь **установить обычный Minecraft и начать игру за один понятный сценарий**, не разбираясь в очереди загрузок, Java, метаданных Mojang или отдельных страницах лаунчера. Внешняя структура ориентируется на предоставленный пример: список сборок слева, одно выбранное содержимое справа, а сложные параметры находятся в раскрываемом разделе. Дизайн Atlas остаётся самостоятельным — тёмная тема **Obsidian Atlas**, собственные названия и графика, без копирования чужого интерфейса или брендинга.

> Основной путь: **«Новая сборка» → имя → версия Minecraft → Vanilla → «Создать и установить» → «Играть»**.

| Элемент из примера | Реализация в Atlas | Почему это необходимо |
| --- | --- | --- |
| Список сборок в боковой колонке | Страница «Библиотека» с видимым выбранным профилем и кнопкой «+ Новая сборка» | Пользователь сразу понимает, где находятся его установки. |
| Единое окно «Изменить сборку» | Диалог `Новая / Изменить сборку` вместо разнесённых действий | Версия, загрузчик и папка настраиваются в одном месте. |
| Выбор Vanilla / Forge / Fabric / Quilt / NeoForge | Пять видимых переключателей загрузчика | Не нужно искать загрузчик в отдельном экране. |
| Выбор версии игры | Комбобокс версий с кнопкой «Обновить список» рядом | Подсказка объясняет, откуда берутся версии и почему нужен интернет. |
| Папка игры | Переключатель отдельной папки профиля / выбранная пользователем папка | Профили не смешивают моды, миры и настройки. |
| «Больше настроек» | Сворачиваемая панель расширенных параметров | Обычный пользователь не видит опасные параметры до необходимости. |
| Максимальная память, Java, JVM-аргументы | Профильные поля с безопасными значениями по умолчанию | Гибкость без обязательной ручной настройки. |
| Разрешение, полноэкранный режим, скрытие лаунчера | Профильные настройки запуска | Это действительно влияет на запуск игры. |

## Экран «Новая / Изменить сборку»

В верхней части — название и краткая строка состояния. Основной блок всегда виден и содержит имя, тип загрузчика, версию Minecraft и место хранения. Внизу расположена только одна основная кнопка.

| Поле | Значение по умолчанию | Поведение |
| --- | --- | --- |
| Название | `Моя сборка` | Обязательное, создаёт понятное имя в списке. |
| Загрузчик | `Vanilla` | Vanilla не требует дополнительного выбора версии загрузчика. |
| Версия Minecraft | Последний стабильный релиз после получения manifest | Если список ещё не загружен, видны «Обновить список» и объяснение. |
| Папка игры | Отдельная папка экземпляра | Создаётся автоматически; пользователь может выбрать другой путь. |
| Создать и установить | Активна после выбора версии | Vanilla запускает реальную установку: metadata, JAR, libraries, assets. |
| Сохранить | Для уже установленного профиля | Сохраняет изменения, не выполняя скачивание. |

## Расширенные настройки профиля

Раскрывающийся блок сохраняется в экземпляре и содержит только реально применяемые настройки.

| Группа | Поля | Безопасное действие |
| --- | --- | --- |
| Экран | ширина, высота, полноэкранный режим | Аргументы игры `--width`, `--height`; полноэкранный параметр, если поддерживает версия. |
| Память | максимум памяти в МБ | `-Xmx` генерируется лаунчером; значение ограничивается доступным диапазоном. |
| Java | локальная Java Atlas / пользовательский `javaw.exe` | По умолчанию используется локально установленная Java, системная Java не требуется. |
| JVM | дополнительные аргументы | Показано предупреждение; нельзя скрытно подменять выделение памяти. |
| Поведение | скрывать лаунчер при запуске | После успешного старта окно скрывается и возвращается после завершения игры. |
| Совместимость | безопасный режим без пользовательских аргументов | Отключает только пользовательские JVM-аргументы, а не механизмы лицензирования. |

## Критерии готовности

1. Новый пользователь видит в библиотеке кнопку **«+ Новая сборка»** и может создать Vanilla-профиль, не посещая страницу настроек.
2. При нажатии **«Создать и установить»** Atlas при необходимости загружает свою Java, затем Vanilla Minecraft, показывает понятный прогресс и не требует повторного выбора версии.
3. После `installFinished` основная кнопка профиля меняется на **«Играть»**.
4. Ошибка сети автоматически повторяется до двух раз, далее объясняется с кнопкой повторной попытки; уже проверенные файлы не скачиваются повторно.
5. Forge, NeoForge, Fabric и Quilt остаются доступны из того же окна, но дополнительные версии загрузчика выводятся только после выбора соответствующего типа.
6. Все основные элементы помещаются при размере окна 800×520 и не выходят за границы; длинный блок настроек прокручивается.

## Что не будет копироваться

Atlas не использует название, логотипы, рекламные баннеры, ссылки, тексты, сетевую инфраструктуру, режимы обхода лицензии или реализацию стороннего лаунчера. Microsoft-вход остаётся только для обладателя Minecraft; офлайн-профиль — для локальной игры и не выдаётся за лицензионный доступ.
