# Сборка Atlas Launcher для Windows и Inno Setup

Этот документ описывает воспроизводимую сборку 64-битной версии Atlas Launcher для Windows 7 SP1 и новее. Для фактической поддержки Windows 7 используйте комплект **Qt 5.15**, собранный с поддержкой Windows 7, и проверяйте готовый пакет на отдельной чистой машине с Windows 7 SP1 x64.

| Компонент | Назначение | Рекомендуемый вариант |
|---|---|---|
| Компилятор | Сборка C++17 | MSVC 2019/2022 x64 или MinGW, совпадающий с комплектом Qt |
| Qt | GUI и сеть | Qt 5.15.x Widgets + Network для Windows x64 |
| CMake | Генерация проекта | 3.16 или новее |
| windeployqt | Сбор зависимостей Qt | Из `Qt/<kit>/bin` |
| Inno Setup | Создание `Setup.exe` | Inno Setup 6 |

## 1. Сборка приложения

В **Developer PowerShell** с выбранным компилятором создайте каталог сборки и выполните команды ниже. Если Qt не найден автоматически, передайте `CMAKE_PREFIX_PATH` — это путь к каталогу Qt-комплекта, содержащему `lib/cmake/Qt5`.

```powershell
cmake -S . -B build-win64 -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_PREFIX_PATH="C:\Qt\5.15.2\msvc2019_64"
cmake --build build-win64 --config Release --parallel
```

## 2. Сбор зависимостей Qt

Не копируйте DLL вручную: запустите входящий сценарий. Он очищает каталог публикации, копирует исполняемый файл и вызывает `windeployqt --release --compiler-runtime --no-translations`.

```powershell
.\scripts\deploy_windows.ps1 `
  -BuildDirectory .\build-win64 `
  -Configuration Release `
  -QtBinDirectory "C:\Qt\5.15.2\msvc2019_64\bin"
```

В результате появится `dist\AtlasLauncher-win64`. Запустите `AtlasLauncher.exe` именно из этой папки и проверьте создание и запуск экземпляра, импорт папки с `package.json`, открытие настроек, локальную Java и поиск каталога.

## 3. Создание установщика

Откройте `installer\AtlasLauncher.iss` в Inno Setup 6 и нажмите **Compile**. Либо выполните команду из PowerShell, задав путь к `ISCC.exe` в соответствии со своей установкой:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" .\installer\AtlasLauncher.iss
```

Готовый файл находится в `dist\installer\AtlasLauncher-Setup-0.2.0-x64.exe`. Скрипт устанавливает программу без обязательных прав администратора, добавляет ярлык в меню «Пуск», опциональный ярлык на рабочий стол и деинсталлятор. Пользовательские данные остаются в папке AppData и не удаляются деинсталлятором.

## 4. Контрольный список перед распространением

| Проверка | Ожидаемый результат |
|---|---|
| Чистая Windows 7 SP1 x64 | Запуск без отсутствующих Qt/MSVC DLL и без аварийного завершения |
| Чистая Windows 10/11 x64 | Установка, запуск и удаление проходят успешно |
| Vanilla и загрузчики | Vanilla, Fabric, Quilt, Forge и NeoForge устанавливаются и запускаются только после успешного завершения официального потока; проверяются как минимум две совместимые версии Minecraft |
| Modrinth | Поиск выдаёт результаты; один первичный файл с опубликованным хешем ставится в корректную папку и корректно сообщает о сетевой ошибке/лимите |
| CurseForge | Без ключа нет запросов; ключ не попадает в `settings.json` и `atlas.log`; одиночный файл с SHA-1 ставится только в корректную папку |
| Импорт пакета | Небезопасные пути с `..` или абсолютные пути отклоняются |
| Обновление | Установка поверх предыдущей версии сохраняет локальные экземпляры |

## Ограничения текущей версии

Сборщик не включает Minecraft, не обходит лицензию и не выполняет обход авторизации. Для входа лицензированного аккаунта владелец лаунчера должен указать собственный Microsoft Application (client) ID; пароль от Microsoft не вводится в Atlas. CurseForge требует персонально выданный ключ и соблюдение текущих условий API; ключ оставлен только в памяти процесса. Modrinth и CurseForge в этой версии устанавливают только одиночные проверяемые файлы модов, ресурспаков и шейдеров: зависимости, модпаки, миры и автоматическое возобновление ещё не реализованы. Перед распространением обязателен реальный прогон на чистой Windows 7 SP1 x64, поскольку в данной среде выполнены компиляция и headless-проверка, но не интерактивное тестирование Windows.
