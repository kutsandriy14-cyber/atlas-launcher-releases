# Визуальная проверка Atlas Launcher 0.3.0

- Разрешение: 1024×768.
- Главная страница полностью помещается в рабочую область: правая граница, нижняя строка состояния и боковая панель видимы.
- Горизонтальная прокрутка и выход карточек за границы окна на этом разрешении не наблюдаются.
- Первая попытка открыть «Библиотеку» не сработала из-за неверного синтаксиса команды управления виртуальной мышью; это не является дефектом интерфейса.

Диалог «Новая сборка» также проверен при 1024×768. Его ширина помещается в экран без горизонтальной полосы прокрутки; элементы основной формы и кнопки действий остаются в границах. Для длинной формы используется вертикальная прокрутка, что ожидаемо и не скрывает поля по горизонтали.
