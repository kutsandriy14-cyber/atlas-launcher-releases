# Визуальная проверка панели параметров каталога

Дата: 2026-08-13.

- Собранный нативный Atlas Launcher успешно открылся в Xvfb; переход на страницу «Каталог контента» подтверждён.
- В интерфейсе видны строка запроса, выбор источника, типа контента, кнопка поиска, список результатов, установка и кнопки страниц, а также отдельная правая карточка «Параметры поиска».
- Правая карточка содержит реальные элементы: «Версия Minecraft», «Загрузчик», «Сортировка» и «Категория». На исходном снимке Qt/Xvfb применил масштабирование дисплея, из-за чего текст визуально плотный; дальнейшая проверка должна выполняться при 96 DPI.
- При начальной асинхронной загрузке категорий Modrinth окружение вернуло `Connection closed`. Это внешний сетевой ответ запуска, а не сохранение ключа или сбой локального интерфейса. Каталог оставил доступными остальные элементы поиска.
- Снимки: `catalog-filter-panel-native.png` и `catalog-filter-panel-page.png`.

## Подтверждённая логика

Новая панель формирует параметры для официальных API Modrinth/CurseForge: версия Minecraft, загрузчик, сортировка, категория и индекс страницы. Ключ CurseForge не записывается в настройки или журнал и нужен только для запроса категорий/поиска в текущем запуске.

## Внешние источники

- Modrinth Search Projects: https://docs.modrinth.com/api/operations/searchprojects/
- CurseForge REST API: https://docs.curseforge.com/rest-api/
